What the method proved

trust = a passing gate, never a spec sheet

GLM has the top leaderboard numbers and is the least reliable candidate on this suite's own gate. The temp-0 probe hid it; the supplementary temp-0.7 check caught it. The gate did real work.

The crash, and the guard

An earlier turn ran the MLX vision model and gemma4:26b at once; unified memory ran out and the kernel's jetsam killer took down every agent on the machine. Fix: scripts/mem-guard.py, a watchdog that kills the largest model process before jetsam fires, never touches agent processes, and logs every action. Plus a strict one-heavy-model-at-a-time rule. It never had to fire; every run after it was clean. It has since self-expired.
