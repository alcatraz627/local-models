# lm

> Local models on this Mac: answers, shell commands, image reads. Nothing leaves the machine unless marked.
> More information: `man lm` or `lm --capabilities`.

- A quick answer from the small local model:

`lm "how do I see what is using port 5432"`

- One shell command, checked before you run it:

`lm cmd "list the 5 largest files in ~/Downloads"`

- Read the text or an answer out of an image:

`lm read shot.png`

- Read your newest screenshot:

`lm read latest`

- Ask about, or summarize, a file:

`lm doc report.pdf`

- The answer was wrong; ask the same thing on a stronger model:

`lm again`

- Search the answers you got before:

`lm find "port 5432"`

- Find the command for what you want, without running it:

`lm how "text from my last screenshot"`
